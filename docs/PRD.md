## 1. 文档概述与产品定位

### 1.1 背景与用户痛点
在复杂项目与现代 AI/多 Agent 协同研发场景中，项目协同面临三大结构性矛盾：
1. **状态流向黑箱**：传统列表或看板（Jira、Trello）是扁平的，无法体现前置依赖如何卡死下游，管理者只知道“在做了”，不知道“电流断在哪里”。
2. **人机边界混淆**：要么过度人工填报导致进度失真，要么过度迷信 AI 导致无客观标准，界面丑陋失控。
3. **视角死板割裂**：不同岗位（业务、前端、后端、测试、数据分析师）各有关注点，硬塞在同一张大表里导致信息过载。

### 1.2 产品定位 (Value Proposition)
FlowTree 是一个**「树状物理电路隐喻 + 数据结构驱动」的可视化任务流转引擎与项目管理平台**：
- **物理电路隐喻**：前置逻辑跑通，导线通电发光、流动粒子注入，下游如灯泡般逐一被点亮；异常时熔断报警。
- **人机边界清晰**：**客观逻辑交给自动化/Agent 重复验证，主观美观与体验保留给人类终审**。
- **动态透镜机制**：支持自定义任意岗位视角（数据分析师、合规、测试等），智能保持上下游因果依赖连通。
- **微内核可独立发包**：渲染核心（`@flowtree/core-canvas`）与业务平台（`FlowTree Platform`）彻底解耦。

## 2. 用户画像与核心旅程

### 2.1 用户角色
| 角色 | 核心关注点 | 在 FlowTree 中的典型动作 |
| :--- | :--- | :--- |
| **项目经理 / PM** | 整体阻塞点、上线风险、人工主观终审 | 规划任务拓扑、自定义业务视角、进行最终的人工体验 Sign-off |
| **研发工程师** | 接口契约、前置依赖是否具备、产出物绑定 | 查看上游接口是否通畅、提交代码产出物、触发逻辑验证 |
| **数据分析师** | 埋点采集链路、数仓清洗进度、指标一致性 | 切换「数据分析师视角」，追踪业务到指标加工的全链路状态 |
| **测试工程师 / QA** | 自动化测试覆盖、冒烟接口通断、外部用例映射 | 配置外部测试套件映射（`externalBinding`），追踪用例执行结果 |
| **外部 Agent (AI Worker)**| 执行客观标准、回报状态 | 自动化追踪外部测试平台并回填标准状态 PATCH |

### 2.2 核心用户旅程 (User Journey)
1. **拓扑规划**：PM 在工作台创建项目，录入任务节点并划定依赖关系（人掌控结构）；
2. **动态切角**：数据分析师或测试人员切换到专属透镜，系统自动隐藏无关技术细节，穿透展现其关键路径；
3. **逻辑通电**：外部测试系统或 Agent 验证通过某接口，推送 PATCH，导线瞬间通电发光（电流粒子动画），下游节点从休眠变为激活（进行中呼吸灯）；
4. **人类终审**：前端功能完成后，客观逻辑（接口 200/测试通过）亮蓝标示 `logic_verified`，PM 打开抽屉审查 UI 美观与交互体验，点击“人工终审通过”，节点翠绿常亮，全链路彻底导通。

### 3.2 详细功能规格说明

#### 模块一：核心电路渲染引擎 (`@flowtree/core-canvas`)
1. **横向树状电路布局**：根节点在左，叶子节点向右展开，支持缩放、拖拽与居中复位。
2. **灯泡元器件节点 (Bulb Node)**：
   - 带有四种发光状态指示器（灰暗休眠、亮黄呼吸、亮蓝待审、翡翠绿常亮、警示红闪烁）；
   - 数据叠加区（Data Overlay）：展示负责人头像、工时占比、测试绑定徽标。
3. **通电发光导线 (Conductive Wire)**：
   - 当前置节点通过时，导线变绿并激活动态电流粒子跑动动画；
   - 存在阻塞时，连线呈现故障警示红断开样式。

#### 模块二：动态视角透镜管理 (Dynamic Perspectives)
1. **预设与自定义视角**：支持管理员创建新视角（如「分析师视角」），设置标签筛选规则（`includeTags`）。
2. **智能穿透/折叠算法**：当非关键路径节点被过滤时，自动以穿透线连接上游已通过节点与下游受影响节点，保持因果不断链。

#### 模块三：两段式质量验收工作台
1. **阶段 1：客观逻辑验证 (Automated Logic Verification)**：
   - 外部 Agent 或测试系统推送接口状态，系统校验客观断言通过后，状态流转为 `logic_verified`（蓝光提示）。
2. **阶段 2：人类体验终审 (Human Sign-off)**：
   - 抽屉面板展示验收标准（AC）、产出物链接与客观测试报告；
   - 专属于人类审查员的验收操作台（通过 / 打回附带审查意见）。

#### 模块四：多项目看板与 Agent 追踪控制器
1. **多项目管理列表**：展示各项目的整体导通率（通过工时 / 总工时）、阻塞卡点数量。
2. **Agent 追踪控制器**：项目详情页提供“开启 Agent 追踪”开关，通知外部 Agent 依照节点绑定的 `externalBinding` 持续同步状态。

## 4. 非功能性需求 (NFR)
1. **响应性能**：单项目 500 个节点级别下，画布平移与缩放保持 60fps 无掉帧；
2. **解耦要求**：`@flowtree/core-canvas` 必须做到零业务网络请求依赖，纯 Props 受控；
3. **实时性**：外部推入 PATCH 状态后，WebSocket 端到端到浏览器渲染延迟小于 100ms。
