## 用户本批得到什么

在临时项目运行初始化，选择用户级 AI 连接，再用同一个项目入口完成离线配置检查或经显式授权的连通检查。无须手工编辑 FlowTree 主机工作区配置。**本批不生成故事，不生成测试，不执行项目业务测试。**

## 范围与具体入口

- `flowtree project init <dir>`：创建 `.flowtree/flowtree.yaml`、材料目录及精确忽略规则；不扫描、不联网、不生成旧电路骨架、不写用户目录配置，不覆盖已有文件。
- 用户级 AI 配置：含具名连接、`openai_chat`、base URL、请求路径、模型、密钥环境变量名及限制。项目配置最多选择连接名；不得覆盖目标地址或密钥来源。本机解释器覆盖与 AI 连接配置分开，不把业务环境变量转发给模型。
- `flowtree ai check --project <dir> --offline [--json]`：实际加载上一步配置与用户级连接，检查规则及密钥存在性，不发请求。不要实现一份无人读取的项目配置。
- `flowtree ai check --project <dir> --allow-send <最终完整地址> [--json]`：显式授权一次最小请求，输出连通与协议结构结果。无交互授权且无精确地址匹配时零请求；不得把 dry-run 当授权。若支持交互，必须展示最终地址及配置来源。
- 明确的用户配置路径参数，用于临时配置和离线测试；缺失时提供模板/设置说明，不隐式创建或覆盖用户级文件。示例以 DeepSeek 为首个目标，实施时核对官方文档的可用模型名，不将提供方写死进协议逻辑。
- `--json` 在成功、缺省和失败路径均输出可解析结构，不把普通提示夹入 stdout。

仅接通初始化配置到本批 ai check；旧 `ws verify/status`、Web 注册、`register`、完整 `--project` 到验证器的映射留后续。不得宣称本批已完成全部项目接入。

## 最小调用边界

1. 复用一种通用聊天协议，不做流式、工具调用、JSON 模式、自动协议回退或自动重试。
2. 保留 base URL 路径前缀，path 不得改变主机；禁止嵌入凭据、查询参数中的密钥及重定向。仅 HTTPS，明确的本机回环假服务可使用 HTTP。
3. 请求前先写调用开始记录并原子占用额度，再发送；完成后追加结果。并发不能超领，崩溃/超时保留未知，不自动返还已可能发送的额度。持久记录与锁限于本机运行产物，不建通用事件平台。
4. 限制由配置明确给出并严格校验。每条命令至多一请求；项目累计上限的计量单位/作用域明确，不以计数器路径变化偷换成“全账户预算”。不配置无限值，不承诺准确金额或模型服务端一定未收费。仅对能准确计量的调用数、输入字节和请求输出上限作保证。
5. 总体超时、输入/响应大小上限、状态码与协议错误有明确结果；缺文本、无效 JSON、截断输出不能成功。
6. 密钥不进参数、日志、错误、配置文件或产物；服务端响应正文可能回显密钥，不能原样打印。记录最少元数据，不保存密钥与完整提示。

## 文件系统与兼容

- `.flowtree/`、待写文件为符号链接或路径类型不符时拒绝；不沿链接写出项目。
- 不改项目根 `.gitignore`。已有内部忽略文件/根忽略冲突时保留并报告，不能谎称已安全忽略。空目录无需出现在 Git 状态中。
- 项目配置、故事/映射/指引/草稿为可审查材料；密钥、本机配置、调用记录、缓存等不入库。不要排除整个 `.flowtree/` 的工作区指纹，也不在本批迁移 LPB。
- 旧 init/run/status/watch 行为不变；既有验证器不依赖 AI、用户级配置或密钥。

## 离线验收（Claude 自测，Codex 独立复验）

| 项 | 必须证明 |
|---|---|
| 完整入口 | 从临时 Git 项目初始化到 ai check，用真实 CLI 子进程与假 HTTP 服务跑通，不手改主机工作区 |
| 零请求 | 初始化、离线检查、未授权、地址授权不匹配、缺密钥时假服务没有收到请求 |
| 一请求 | 成功或失败均不自动重试；HTTP 确实使用配置的前缀与路径 |
| 调用失败 | 鉴权、限额、超时、响应过大、无效 JSON/文本、重定向都有明确结果，无密钥回显 |
| 预算 | 两个并发 CLI 不越上限；请求开始后崩溃/超时不凭空恢复额度；只读检查不扣额度 |
| 写入安全 | 重复初始化不覆盖；链接/路径冲突拒绝；已有故事不变，根忽略文件不变 |
| 协议独立 | 假服务使用非 DeepSeek 名称/自定义路径仍成功，未知协议明确拒绝 |
| 兼容 | 相关旧命令与上下文/证据回归通过；不必重跑不相关 Flutter、真实 LPB 或浏览器业务测试 |
