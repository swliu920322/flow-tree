## GUIDE-01：重复指引仍留下 current / stale 候选

`load_guides()` 对重复故事只增加集合级诊断，`get(story_id)` 仍返回首份指引，状态可能是 current 或 stale。按文件顺序选择不能解决内容冲突，调用方读取单条结果时可能遗漏集合级错误。

要求：重复故事的可获取结果必须 invalid，或不返回候选并保留明确诊断。不能以首份文件优先解决冲突。两条独立反例分别覆盖首份 current 和首份 stale。

## GUIDE-02：故事语义无效，指引仍判 current

故事能通过模型解析但 continuation 指向不存在的步骤时，`LoadedStory.story` 仍存在，同时带语义错误。指引只检查 story 是否为 None；若摘要匹配，就判 current。

要求：引用故事本身有错误时，指引必须 invalid，并说明原因。不要让其他无关故事的错误连带污染有效故事。

## GUIDE-03：账号一致性检查把注释当作播种声明

正则扫描整份脚本，注释中的 `user(...)` 也会被收集，再被 `dict(users)` 静默覆盖。独立反例中实际播种“新显示名”，末尾旧注释写“旧显示名”，检查读到的是旧值，可能让与真实播种不一致的指引通过。

要求：只解析实际播种 Python 片段中的声明，不执行脚本。可使用 AST；不支持的声明方式应明确失败，不能猜测或静默覆盖重复账号。该逻辑继续留在样例专项测试，不进通用引擎。
